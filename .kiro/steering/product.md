# Product Steering: sandikodev.github.io

## Vision

Portfolio blog dengan dual design system yang memperkenalkan "geek world" kepada awam - membuktikan bahwa terminal, tiling WM, dan Linux aesthetic tidak menakutkan, justru powerful dan accessible.

## Goals

1. **Blog profesional** - Berbagi pengetahuan development
2. **Playground interaktif** - Eksplorasi UI/UX terminal aesthetic
3. **Educational tool** - Memperkenalkan Linux/terminal culture
4. **Personal branding** - Showcase skills dan personality

## Target Audience

| Audience | Mode | Needs |
|----------|------|-------|
| General readers | Blog Mode (📝) | Clean, readable content |
| Developers | Dev Mode (💻) | Terminal aesthetic, keyboard-driven |
| Linux enthusiasts | Dev Mode (💻) | i3wm experience, ricing |
| Recruiters | Blog Mode (📝) | Professional portfolio |

## Core Features

- Dual design system (Blog ↔ Dev Mode)
- Route mirroring (`/` ↔ `/workspace/`)
- Theme customization (Tokyo Night, Dracula, etc.)
- Keyboard-driven navigation
- SEO optimized (double indexing)

## Tech Stack

- **Framework**: Astro 5.x (Static Site Generation)
- **Styling**: Tailwind CSS + Custom CSS
- **Fonts**: Inter, Georgia, Fira Code
- **Deployment**: GitHub Pages
- **Package Manager**: pnpm

## Success Metrics

- User engagement dengan Dev Mode
- SEO visibility untuk "terminal blog", "developer workspace"
- Positive feedback dari ricing community
