#### `/src/components/ReadingTime.astro`

- Display reading time and word count
- Icon with time estimate

#### `/src/components/SocialShare.astro`

- Share buttons for Twitter, Facebook, LinkedIn

- Lazy loading images

- FAQ with accordion UI
- FAQ schema included
- Usage: `<FAQ items={[{question: "Q?", answer: "A"}]} />`

## 🎯 Usage Examples

### In Blog Posts (PostSingle.astro)

```astro
---
import ReadingTime from "@/components/ReadingTime.astro";
import SocialShare from "@/components/SocialShare.astro";
import Breadcrumb from "@/components/Breadcrumb.astro";

const breadcrumbs = [
  { name: "Home", url: "/" },
  { name: "Blog", url: "/blog" },
  { name: post.data.title },
];
---

<Breadcrumb items={breadcrumbs} />
<ReadingTime minutes={readingTime} words={words} />
<Content />
<SocialShare title={title} url={`https://sandikodev.github.io/${post.slug}`} />
```
